# 우테코 8기 최종 코딩테스트: XXX 요구사항 분석 및 정리

## 제시된 요구사항 정리 및 분석

반환되는 동전이 최소한이 되는 자판기를 구현한다.

- 자판기가 보유하고 있는 금액으로 동전을 무작위로 생성한다.
    - 투입 금액으로는 동전을 생성하지 않는다.
- 잔돈을 돌려줄 때 현재 보유한 최소 개수의 동전으로 잔돈을 돌려준다.
- 지폐를 잔돈으로 반환하는 경우는 없다고 가정한다.
- 상품명, 가격, 수량을 입력하여 상품을 추가할 수 있다.
    - 상품 가격은 100원부터 시작하며, 10원으로 나누어떨어져야 한다.
- 사용자가 투입한 금액으로 상품을 구매할 수 있다.
- 남은 금액이 상품의 최저 가격보다 적거나, 모든 상품이 소진된 경우 바로 잔돈을 돌려준다.
- 잔돈을 반환할 수 없는 경우 잔돈으로 반환할 수 있는 금액만 반환한다.
    - 반환되지 않은 금액은 자판기에 남는다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException를 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 해당 부분부터 다시 입력을 받는다.
- 아래의 프로그래밍 실행 결과 예시와 동일하게 입력과 출력이 이루어져야 한다.

### 검증

**상품 등록**

- 상품 가격이 올바른지 검증한다.
    - 상품 가격은 100원부터 시작하며, 10원으로 나누어떨어져야 한다.

**상품 구매**

- 구매하려는 상품의 재고가 충분한지 판단한다.
- 구매하려는 상품이 존재하는지 판단한다.

### 기능

- 상품 정보를 등록할 수 있다.
- 자판기 보유 금액에 맞게 동전을 무작위로 생성한다. (투입 금액 아님!)
- 요청받은 상품을 구매한다.
- 더 이상 구매가 불가능한지 판단한다.
    - 남은 금액이 상품의 최저 가격보다 적거나, 모든 상품이 소진된 경우 바로 잔돈을 돌려준다.
- 잔돈으로 반환할 수 있는지 판단한다.
    - 잔돈으로 반환할 수 있는 경우, 잔돈을 돌려줄 때 현재 보유한 최소 개수의 동전으로 잔돈을 돌려준다.
    - 잔돈으로 반환할 수 없는 경우, 잔돈으로 반환할 수 있는 금액만 반환한다.

### 입력

- 자판기가 보유한 금액을 입력받는다.
    - 예외 상황: 정수가 아닌 경우
- 상품명과 가격, 수량을 입력받는다.
    - 예외 상황: 포맷이 올바르지 않은 경우, 가격과 수량이 정수가 아닌 경우

- 투입 금액을 입력한다.
    - 예외 상황: 정수가 아닌 경우
- (잔돈이 충분하면) 구매할 상품명을 입력한다. x N

### 출력

- 자판기가 보유한 동전을 출력한다.
- 자판기가 보유한 잔돈을 출력한다.

## 도메인 정리

### 상품(엔티티)

- 상품 가격(VO)
- 상품 이름(VO)
- 상품 재고(VO)

#### 상품 가격(VO)

- 상품 가격은 100원부터 시작하며, 10원으로 나누어떨어져야 한다.

#### 상품 이름(VO)

- 상품 이름은 비어있을 수 없다.

#### 상품 재고(VO)

- 상품 재고는 0 이상이다.
- 상품 재고를 차감할 수 있다.
    - 차김 시 재고가 충분한지 검증한다.

### 동전

- 500, 100, 50, 10원으로 구성된다.

### 동전 수량

- 동전
- 수량

### 자판기

- 동전 수량 목록
- 고객 투입 금액

- 초기 금액에 맞게 동전을 무작위로 구성한다.
    - 초기 금액은 10원 단위로 구성되어야 한다.
- 남은 금액을 계산할 수 있다.
- 상품 구매 요청을 처리한다.
- 더 이상 구매가 불가능한지 판단한다.
- 잔돈을 반환한다.

## 유즈케이스 정리

- 자판기 보유 금액을 구성한다.
- 상품을 등록한다.
- 금액을 투입한다.
- 상품을 구매한다.

## 비즈니스 로직 정리

- 자판기 보유 금액을 구성한다.
    - 자판기 동전 보유 개수를 저장해둔다.
- 상품을 등록한다.
    - 상품 정보를 저장해둔다.
- 금액을 투입한다.
    - 자판기

- 상품을 구매한다.
    - 더 이상 구매가 불가능한지 판단한다.
    - 요청한 상품이 존재하는지 판단한다.
    - 남은 고객 금액으로 상품 구매가 가능한지 판단한다.
    - 재고가 충분한지 판단한다.
    - 상품 재고를 차감한다.
    - 남은 고객 금액을 차감한다.

- 더 이상 구매가 불가능한 경우, 잔돈을 반환한다.
    - 자판기 보유 동전을 이용하여 남은 고객 금액을 구성한다.

## Layer 구분

### MenuSelectDispatcher(Presentation Layer)

- 사용자가 선택한 메뉴를 처리할 수 있는 Controller를 찾아 처리하도록 합니다.(dispatch)

### Controller(Presentation Layer)

- 사용자 요청을 받아 유즈케이스를 처리하고, 그 결과를 사용자에게 반환합니다.

### ConsoleInputAdapter(Presentation Layer)

- 사용자 입력을 Application이 처리할 수 있는 형태로 변환합니다.
- 입력을 위한 콘솔 프롬프트를 담당합니다.

### Application Service

- Application이 처리하는 유즈케이스를 담당하고, 비즈니스 로직 오케스트레이션 및 트랜잭션 경계를 담당합니다.

### Domain Service

- 도메인 객체 생성 및 도메인 로직 수행을 담당합니다.
- Bounded Context를 넘어가거나 여러 도메인 객체가 협력해야 하는 로직을 담당합니다.
